Privacy Policy

Last updated: November 17, 2026

Fabrica YouTube is a private tool. It is used only by the owner of the YouTube channels it connects to.

What it accesses

With the owner's permission (Google sign-in), the tool uses the YouTube Data API and the YouTube Analytics API to:

  • upload videos, thumbnails, titles and descriptions to the owner's own channels;
  • schedule or publish those videos;
  • read views, likes, comments and other statistics of the owner's own channels.

Where the data is kept

The sign-in tokens and statistics are stored only on the owner's own computer. They are not sold, shared or sent to anyone else.

How to remove access

Access can be removed at any time at myaccount.google.com/permissions.

The tool's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
